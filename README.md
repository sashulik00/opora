# Опора. Школа ухода

Учебный сайт для семей участников СВО: уроки, памятки, практика и поддержка.

Сайт можно открыть просто файлом (`index.html`) — тогда вход и прогресс хранятся только в этом браузере.
Чтобы работали регистрация с паролем и сохранение прогресса в базе, нужно запустить локальный сервер.

## Как запустить на своём компьютере

Нужны **Node.js** (версия LTS, https://nodejs.org) и **Docker Desktop** (https://www.docker.com). Docker Desktop должен быть запущен.

Все команды — в PowerShell (например, в терминале VS Code), в папке проекта.

**1. Настройки (один раз).** Скопируйте образец настроек:

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и поменяйте:
- `POSTGRES_PASSWORD` — придумайте пароль базы и впишите его же в `DATABASE_URL` и `TEST_DATABASE_URL` вместо `change_me`;
- `JWT_SECRET` — длинная случайная строка. Получить её можно командой:

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

Файл `.env` в git не попадает — в нём пароли, никому его не показывайте.

**2. База данных.** Запустите PostgreSQL в Docker:

```powershell
docker compose up -d
```

Первый раз Docker скачает образ — это займёт минуту-две. Проверить, что база работает: `docker compose ps` (в строке `db` должно быть `healthy`).

**3. Библиотеки (один раз и после изменения package.json):**

```powershell
npm install
```

**4. Сервер:**

```powershell
npm start
```

Появится «Сервер запущен. Сайт: http://localhost:3000». Таблицы в базе создаются сами при первом запуске.

**5. Сайт:** откройте в браузере **http://localhost:3000**

Остановить сервер — `Ctrl + C` в окне, где он запущен. Остановить базу — `docker compose stop` (данные сохранятся в папке `pgdata`).

**6. Тесты** (база из шага 2 должна работать, сервер — не обязательно):

```powershell
npm test
```

Тесты используют отдельную базу `opora_test` (создаётся сама) и не трогают данные сайта.

### Если что-то не так

- **«Не удалось подключиться к базе данных»** — не запущена база: `docker compose up -d`, и проверьте, что Docker Desktop открыт.
- **«password authentication failed»** — пароль в `.env` не совпадает с паролем базы. Пароль задаётся только при самом первом запуске базы: верните прежний пароль или удалите папку `pgdata` (все зарегистрированные пользователи пропадут) и снова выполните `docker compose up -d`.
- **«Не получается запустить сервер — проверьте файл .env»** — нет файла `.env` или в нём не заполнен `JWT_SECRET` (шаг 1).
- **Порт 3000 занят** — поменяйте `PORT` в `.env`, например на `3001`, и откройте http://localhost:3001

## ИИ-консультант (Яндекс AI Studio)

Консультант (страница «Консультант») отвечает только по материалам сайта: на каждый вопрос сервер находит
2–3 подходящие темы в `js/data.js` и передаёт их текст модели Яндекса. Работает только для вошедших.

**Что положить в `.env`** (добавьте строки в уже существующий `.env`, остальные строки не трогайте):

```
YANDEX_CLOUD_API_KEY=ваш API-ключ
YANDEX_CLOUD_FOLDER=ID каталога (вида b1g...)
YANDEX_CLOUD_MODEL=aliceai-llm-flash/latest
YANDEX_API_BASE_URL=https://ai.api.cloud.yandex.net/v1
```

Последние две строки можно не писать — тогда возьмутся эти значения. После изменения `.env` перезапустите сервер (`Ctrl + C`, потом `npm start`).

**Как проверить руками:**
1. `docker compose up -d`, затем `npm start`, откройте http://localhost:3000 и войдите.
2. Откройте «Консультант» и спросите: «Как обрабатывать ожог?» — придёт ответ по шагам и строка «Источники: урок «Ожоги»».
3. Спросите: «Какую мазь купить?» — консультант должен ответить, что в материалах этого нет, и посоветовать урок.
4. Напишите: «он не дышит» — сразу появится красный блок «Немедленно звоните 103 или 112» (ИИ при этом не вызывается).
5. Без ключа (или если Яндекс не отвечает) придёт «Консультант сейчас недоступен» и список уроков; причина ошибки — в окне сервера.

Тесты консультанта (`npm test`) настоящий Яндекс не вызывают — модель в них подменена заглушкой.

## Что где лежит

- `*.html`, `css/`, `js/`, `images/`, `fonts/` — сам сайт. Тексты и задания — в `js/data.js`.
- `js/store.js` — вход и прогресс: через сервер или, если сервера нет, в памяти браузера.
- `server/` — сервер (Node.js + Express): `app.js` — API и раздача сайта, `db.js` — база, `tests/` — тесты.
- `server/consultant.js` — консультант (инструкция для модели, порядок ответа), `knowledge.js` — поиск по темам,
  `alarm.js` — тревожные слова, `yandex.js` — подключение к Яндексу.
- `tools/make-masks.py` — маски для практики «Что здесь не так» (запускать после добавления картинок).
