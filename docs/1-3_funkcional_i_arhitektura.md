# 1.3 Функционал и архитектура

## Роли
| Роль | Что может |
|---|---|
| Гость | Смотреть уроки и справочник, проходить тесты (результат не сохраняется), пользоваться консультантом, открывать страницу помощи |
| Пользователь | Всё то же, плюс сохранение прогресса и результатов тестов, личный кабинет |
| Администратор | Добавляет и правит темы, видео, вопросы тестов и список служб |

## Функционал
1. **Главная:** три раздела помощи, переход в уроки и справочник.
2. **Регистрация и вход:** имя и почта.
3. **Уроки:** 16 тем в 3 разделах, можно идти по порядку или выбрать любой, полоса прогресса «Пройдено N из 16».
4. **Страница урока:** видео, памятка («Что делать», «Чего нельзя», «Когда срочно к врачу»), тест с зачётом от 70%, кнопка «Завершить урок».
5. **Справочник:** поиск по темам, фильтр по разделам, статья-памятка без видео и теста.
6. **Личный кабинет:** прогресс, результаты тестов, кнопка «Продолжить».
7. **ИИ-консультант:** чат, подсказывает нужный урок, при тревожных словах показывает «Позвоните 112».
8. **Помощь:** контакты реальных служб, мини-опрос «Как вы себя чувствуете?» для ухаживающего.
9. **Администрирование:** добавление и правка тем, видео, вопросов тестов и списка служб.

Премиум-подписка и оплата есть только в бизнес-модели, на сайте не реализуются.

## Архитектура
Клиент-серверное приложение. Схема в файле `1-3_arhitektura.excalidraw`.

```
Браузер (HTML, CSS, JavaScript)
        │  HTTP, JSON
        ▼
Сервер (Node.js + Express)
  ├─ API: регистрация, вход, прогресс, чат, темы
  ├─ ИИ-консультант (YandexGPT или заготовленные ответы)
  └─ База данных Postgresql
Видеофайлы: хранилище S3 (Yandex Object Storage)
```

| Компонент | Технология |
|---|---|
| Фронтенд | HTML, CSS, JavaScript |
| Бэкенд | Node.js, Express |
| База данных | Postgresql |
| Видео | S3 (Yandex Object Storage) |
| ИИ-консультант | YandexGPT через сервер |
| Развёртывание | Docker, публикация сайта в интернете |
| Репозитории | GitHub (основной), SourceCraft (зеркало) |

## Данные
| Таблица | Поля |
|---|---|
| users | id, имя, почта, дата регистрации |
| topics | id, название, раздел, описание, памятка |
| videos | id, topic_id, путь к файлу в S3 |
| questions | id, topic_id, вопрос, варианты, верный ответ |
| progress | id пользователя, id темы, лучший результат, тест сдан, урок завершён |
| contacts | id, название, описание, ссылка |

## Запросы API
| Запрос | Назначение |
|---|---|
| POST /api/register | регистрация |
| POST /api/login | вход |
| GET /api/topics | список тем |
| GET /api/topics/{id} | одна тема |
| GET /api/progress | получить прогресс |
| POST /api/progress | сохранить результат теста или завершение урока |
| POST /api/chat | вопрос консультанту |
| GET /api/contacts | список служб |
