# 1.1 Анализ предметной области

## О чём проект
«Опора. Школа ухода» — веб-приложение для семей, которые ухаживают дома за ранеными участниками СВО. Оно собирает в одном месте видеоуроки, тесты, справочник и ИИ-консультанта.

## Предметная область
Область проекта — домашний уход и поддержка семьи после возвращения раненого из госпиталя. Её можно разделить на три направления:

1. **Медицинский уход:** ожоги, раны и швы, пролежни, уход после ампутации, перемещение и подвижность, питание и режим.
2. **Психологическая поддержка:** стресс и тревога у бойца, бессонница и кошмары, приступы агрессии, общение с раненым, выгорание у ухаживающего, поддержка детей.
3. **Социально-правовая помощь:** документы и статус, выплаты и льготы, медосвидетельствование и инвалидность, бесплатные протезы и средства реабилитации.

## Участники
- **Родственники раненых** — основная аудитория, ухаживают дома без медицинского образования.
- **Участники СВО на восстановлении** — могут сами искать информацию о своём состоянии.
- **Волонтёры и соцработники** — используют материалы как справочник.

## Существующие решения
| Решение | Что даёт | Чего не хватает |
|---|---|---|
| СВОИРОДНЫЕ.РФ | Ориентирован на участников СВО и их семьи, доступен онлайн круглосуточно, есть живые специалисты и очная помощь, известен и поддерживается государством | Нет практических уроков по уходу и ИИ-консультанта |
| Фонд «Защитники Отечества» | Ориентирован на участников СВО, есть живые специалисты и очная помощь, известен и поддерживается государством | Нет практических уроков по уходу, нет онлайн-доступа 24/7, нет ИИ-консультанта |
| Школа родственного ухода (Москва) | Практические уроки по уходу, онлайн-доступ 24/7, живые специалисты | Не ориентирована на участников СВО, нет ИИ-консультанта |

### Сравнение с «Опорой»
| Критерий | СВОИРОДНЫЕ.РФ | Фонд «Защитники Отечества» | Школа родственного ухода | Опора |
|---|---|---|---|---|
| Фокус на участниках СВО | ✓ | ✓ | ✗ | ✓ |
| Практические уроки по уходу | ✗ | ✗ | ✓ | ✓ |
| ИИ-консультант | ✗ | ✗ | ✗ | ✓ |
| Онлайн-доступ 24/7 | ✓ | ✗ | ✓ | ✓ |
| Живой специалист, очная помощь | ✓ | ✓ | ✓ | ✗ |
| Господдержка и известность | ✓ | ✓ | ✓ | ✗ |

«Опора» закрывает то, чего нет у конкурентов: практические уроки по уходу именно для семей участников СВО и ИИ-консультант. Слабые стороны — нет живого специалиста и известности. Их планируется компенсировать партнёрствами с фондами.

Волонтёры в госпиталях обучаются очно через организации (например, «Сестры милосердия»). С «Опорой» это не конкуренция: аудитория проекта — семьи, которые ухаживают дома и в такие программы не попадают.

## Выводы
- Информация по теме есть, но разбросана по разным сайтам и организациям.
- Очные школы привязаны к городу и расписанию, а семье помощь нужна в момент возникновения проблемы.
- Нет единого места, где можно выбрать конкретную ситуацию и сразу получить нужный материал.
